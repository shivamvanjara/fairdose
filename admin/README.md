# FairDose Admin

The admin dashboard is a standalone Vite application within the FairDose monorepo. For the repository layout and deployment setup, see the [root README](../README.md).

Run the app from this directory:

```sh
npm install
npm run dev
npm run build
npm run lint
```

For its existing hosting project, set the hosting root directory to `admin`; the build output directory is `dist`.
